## 💡 Interview Tips

- 🗣️ **Explain out loud** — interviewers care about _how_ you think, not just the final answer.
- ✍️ **Always code on a whiteboard/editor** — don't just talk theory for coding problems.
- 🔍 **Mention edge cases** — empty arrays, `null`, async timing, etc.
- ⏱️ **Time yourself** — practice explaining each concept in under 2 minutes.
- ❓ **Ask clarifying questions** before jumping into coding problems.
